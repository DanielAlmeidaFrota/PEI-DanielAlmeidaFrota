# Campanha PEI 2027: Diretoria de Operações (TOps)

## Sobre este repositório
Este repositório centraliza a minha candidatura a Diretor de Operações da Orc'estra Gamificação no Processo Eleitoral Interno de 2027.

Ele funciona como um painel de controle para organizar minhas atividades relacionadas a este processo, manter o conhecimento adquirido centralizado em um só lugar, mapeando as dores operacionais da empresa e conectá-las às metas do PE da Rede 25-27 e do Mapa Estratégico da Orc'estra.
Por aqui vou controlar os prazos do edital, documentar os 7 *benchmarks* obrigatórios, rascunhar a Carta de Motivação e preparar a apresentação para a Sabatina.
